# 집대리 — 문의·매칭·채팅 & 매니저 매니징

> 2026-07-23. [10](10_컨시어지모델_컨설턴트중개.md)·[11](11_컨설턴트양성_이탈방지.md) 상위. ※ 기획 + 내 관점.

---

# 1. 통합 인입 — CS 문의부터 견적 상담까지 한 파이프라인

```
CS 문의 · 견적 요청 · 에누리 요청  →  하나의 인입(Inbox)  →  매니저 배정
```
- 소비자의 모든 진입(단순 문의 ~ 구체 견적)이 **한 흐름**으로 들어옴.
- 각 인입은 상태를 가짐: 신규 → 배정 → 상담중 → 견적 → 계약 → 종료/보류.
- → 이전 "확인 필요"에 있던 **플랫폼 CS·문의**가 여기서 확정됨.

---

# 2. 지역 기반 매니저 매칭

```
소비자 위치/현장 지역  →  지역 전담 매니저 자동 매칭
                        ↘ 부재·과부하 시 → 본사 매니저 폴백/에스컬레이션
```
- **전담 매니저 = 내 지역 매니저** 우선 배정.
- 지역 매니저 없음·응답지연·복잡건 → **본사 매니저**가 받거나 에스컬레이션.
- 소비자는 **매니저 1명하고만**(§10 철칙). 배정 규칙: 지역 → 부하 → 전문분야.

---

# 3. 플랫폼 채팅 — "당근 모델"

소비자 ↔ 매니저(또는 본사) 대화를 **플랫폼 안에서**.
- **리치미디어**: 사진·동영상 업로드/다운로드 원활 (시공 전후·현장 사진이 핵심).
- **채팅 내 결제**: 대화 흐름에서 바로 결제(당근페이처럼) → §12 결제·정산과 직결.
- 읽음표시·푸시알림·빠른답변(스니펫, 현행 SMS 상용구 계승).
- 계약·시공·문의 **어떤 개체에도 스레드**를 붙임(§05 Thread).

---

# 4. ★ 카톡 vs 플랫폼 채팅 — 내 관점

사용자 직관 정확함: **"플랫폼 채팅이 원활하면(사진·영상·결제) 플랫폼 채팅이 낫다."**

## 4.1 전략적으로 in-platform이 맞다
- **이탈방지(§11 L2)**: 대화·사진·결제가 앱 안에 있으면 매니저가 직거래로 못 빼감.
  카톡으로 새면 **플랫폼이 대화를 못 보고**, 매니저가 개인적으로 가져가기 쉬움.
- **데이터**: 상담·사진·결제가 전부 남아 분석·후기·감사(§07-10)에 쓰임.
- **결제 일체화**: 당근처럼 대화→결제가 끊김 없음.

## 4.2 단, 한국 현실 — 카톡 습관
- 한국 사용자는 **카톡을 압도적으로** 씀. 새 채팅앱 저항이 큼.
- → **알림톡은 버리지 말고 "유입 채널"로** 쓴다:
  ```
  카톡 알림톡(딥링크) → 앱 채팅으로 끌어들임   (대화 장소 ✗, 재호출 신호 ○)
  ```
- 초기엔 **카톡 핸드오프 허용**(fallback)하되, 플랫폼 채팅 품질(속도·미디어·결제)을 올려
  점차 **인앱으로 이동**. 카톡은 알림·재방문용, 대화·결제는 인앱이 목표.

> 결론: **인앱 채팅을 진짜 좋게 만들되, 알림톡으로 사람을 앱으로 당긴다.**
> 카톡을 대화·결제 무대로 삼으면 이탈방지가 무너진다.

# 5. 매니저 매니징 페이지 (신규)

컨설턴트가 **자기에게 들어온 문의·견적을 평가하고 소통**하는 작업 콘솔.

| 영역 | 기능 |
|---|---|
| 인입함(Inbox) | 배정된 문의·견적 리스트, 상태·우선순위, 신규 알림 |
| 평가(Triage) | 문의 성격·구매의향 평가, 품목 파악, 번들 가능성 |
| 소비자 통합뷰 | 그 소비자의 **모든 단품·이력·채팅**을 한 화면(§10) |
| 소통 | 채팅(사진·영상·결제) + 필요시 통화 |
| 견적·협상 | 번들 견적 작성 → 소비자 제시 → 파트너 조율 |
| 전환 | 견적 → **계약**(파트너 워크스페이스에 초안 생성) |
| 실적 | 배정·전환율·취소율·커미션 |

- 본사 매니저용 상위 뷰: 전 지역 인입·매니저 부하·에스컬레이션 관리.

---

# 6. 이탈방지 연결 (요약)
```
인앱 채팅 + 인앱 결제(당근식)  =  §11 L2 "rails를 플랫폼이 쥔다"
매니저가 대화·돈을 앱 밖으로 못 빼냄 → 직거래 어려움
알림톡 = 사람을 앱으로 되부르는 신호(유입), 대화 무대 아님
```

---

# 7. 기능 지도 반영 (신규/이동)
- **신규 카드**: 문의·매칭·채팅 (통합 인입, 지역 매칭, 본사 에스컬레이션, 플랫폼 채팅[사진·영상], 채팅 내 결제, 카톡 유입)
- **매니저 콘솔 → 매니저 매니징**: 문의·견적 평가(triage), 배정 수락·전환 추가
- **소비자 앱**: "문의하기(CS·견적)" 추가
- **확인 필요에서 제거**: 플랫폼 CS·문의 (확정됨)
