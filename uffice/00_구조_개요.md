  └─ 시공 (Sigong) ── idx / SigongIdx / sidx (예: 22891)   [1:N]

## 6. 검색 파라미터 (searchfrm → GET)

전 페이지 링크에 아래 세트가 통째로 붙어 다님 (상태 유지용):
```
ctGubun, date_start, date_end, field, page, oa, ob,
oc_val, oaa_val, obb_val, occ_val,
keyword(아파트명), keyword1(동호수), keyword2(계약자명), keyword3(전화번호),
apttype, payabled, agency, gisa, manager, gubun3
```

- 체크박스 그룹(`occ`/`oaa`/`obb`/`oc`)은 `fnSearch()`에서 콤마 join 후 hidden `*_val`에 담아 전송
- `ctGubun=='홈케어'` 이면 `obb`/`oc` 체크 강제 해제
- `gubun3`(지점)는 체크박스지만 **hidden 취합 로직 없음** → 다중선택이 GET에 그대로 배열로 나감 (§8 참조)
