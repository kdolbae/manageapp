# 1. 확정 — 채팅은 처음부터 인앱

- **카톡 핸드오프 없음.** 대화·사진·영상·결제 전부 **앱 안에서**(§14, 당근식).
- 카톡(알림톡)은 **대화 무대가 아니라 알림·딥링크**로만: "새 메시지 → 앱으로".
- → 이탈방지(§11 L2) 최강 형태. 매니저가 대화·결제를 앱 밖으로 못 뺀다.

## 1.1 확정 — 관리자·매니저는 PC로 처리
```
소비자 = 모바일 앱   ↔   매니저/관리자 = PC 웹 콘솔
```
- 같은 대화를 **매니저는 PC에서** 실시간 처리(다건 동시, 키보드 응대, 파일 관리 용이).
- §14 "매니저 매니징 페이지" = **PC 실시간 채팅 콘솔** 포함.
- 반응형: 매니저도 모바일 가능하되, 주 작업 환경은 PC.

---

# 2. 확정 — 매칭 = 지역기반 자동 + 관리자 배정권한

```
1차: 지역기반 자동 배정 (내 지역 전담 매니저)
2차: 관리자가 수동 재배정/지정 (권한 보유)
폴백: 본사 매니저 에스컬레이션
```
- 자동이 기본, **관리자는 언제든 개입·재배정** 가능.
- (전문분야 가중 등은 후순위 — 우선 지역+수동으로 단순하게.)

# 3. 신규 — 시공자·파트너 패널티 / 신뢰점수 시스템 ★

## 3.1 관점 — "벌"이 아니라 "신뢰점수(carrot + stick)"
패널티만 있으면 성실한 시공자(우리 핵심 공급)가 **위축·이탈**한다.
→ **양방향 점수**로 설계: 잘하면 **리드가 늘고**, 못하면 **줄어든다.**
```
신뢰점수 ↑  →  리드 우선배정 · 우수배지 · 빠른정산
신뢰점수 ↓  →  리드 제한 · 경고 · (누적 시) 퇴출
```
→ **품질이 스스로 교정되는 루프.** §07 "성실 시공자 선정"과 §11 이탈방지를 강화.

## 3.2 위반(패널티) 유형
| 유형 | 예 |
|---|---|
| 이행 | 노쇼·지각·무단취소·일정 미준수 |
| 품질 | 하자·재시공·시공 미달·A/S 반복 |
| 고객 | 컴플레인·불친절·후기 저평가 |
| 규정 | **직거래 유도(이탈)** · 후기 조작 · 정산규정 위반 |
| 안전 | 보험 미비(성숙기) · 안전수칙 위반 |

## 3.3 조치 단계
```
경고 → 신뢰점수 차감 → 리드배정 제한 → 정산 보류/차감 → 등급 강등 → 계약해지·퇴출
```
- 경중별 자동/수동. **직거래 유도**는 중대 위반(정착금 clawback §11 연계).

## 3.4 반드시 지킬 것 — 투명·공정 (안 그러면 역효과)
- 성실한 시공자가 타깃이므로, **불투명·자의적 패널티 = 이탈**로 직결.
- 필수: **명시된 규칙표** · **이의제기(appeal)** · **이력 전량 보존**(감사, §07-10) · 소명 기회.
- 점수 산정 근거를 파트너가 **자기 대시보드에서** 확인.

## 3.5 소비자 노출은 신중히
- 소비자에겐 **긍정 지표만**(평점·우수배지·인증). 원점수·패널티 내부용.

# 4. 연결
```
신뢰점수 → 리드 우선순위(§14 매칭)   : 성과가 곧 일감
패널티(직거래) → 정착금 clawback(§11) : 이탈방지 집행 수단
품질/AS 실패 → 패널티(§12 AS)        : 보증 신뢰 유지
성실 공급 선정(§07) + 점수 루프       : 품질 해자
```
