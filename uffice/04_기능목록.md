## Q3. 계약 약관 (계약서에 고정 문구)
- 제1조 A/S 기간: 시공일 기준 **10년** 무상 보수 (서비스품목 제외)

- 확인사항 7종 (나노코팅 성능 한계, 메탈 소재 제외, 포세린타일 약정 등)
- 시공 순서: 베란다칠 → 줄눈 → 입주청소 → 새집증후군 ↔ 나노코팅

## Q5. 계약서 메일 발송 방식
`contractMail()` 이 **화면 DOM을 그대로 긁어 메일 본문으로 전송**한다:
```js
$('script').remove();          // ← 현재 페이지의 모든 script 태그를 실제로 삭제
$('.nomail').hide();
$('.mailOnly').show();
var vHtml = $('#mailbody').html();   // DOM 스냅샷
$('#mailform #mailbodyArea').val( vHtml );
$('#mailform').submit();
```
- 체크박스는 `.mailOnly` 의 **이미지(chk_checked.png)로 치환**해 메일에 넣는다
- `$('script').remove()` 가 **원본 페이지의 스크립트를 파괴** → 발송 후 페이지 기능이 죽는다 ★
- 메일 본문이 화면 마크업에 종속 → 화면 수정 시 계약서 서식이 함께 깨짐
