>
> 4개 앱 모두 각 계정으로 로그인해 내부를 수집했다. **10장** 참조.

```
④ 수납정보등록 → bill_pay_reg() → tablet_done()  → ?act=done&contractseq=
```

### 10-4. `/c/` 고객확인페이지 (고객 모바일)

- 로그인: **이름 + 휴대폰번호** (`login_id`=이름, `login_pwd`=휴대폰번호, type=text)
- 메인 `/c/sigong/` = **나의 계약리스트** — "고객님께서 체결하신 계약리스트입니다."
- 목록 항목 클릭 → `fn_list_detail(idx)` → `/c/ajax/ajax_list.asp` POST → 같은 화면에 상세 인라인 렌더
- 쓰기 기능 없음. 후기 작성 화면도 없다(`review.asp` 빈 응답). **조회 전용**
- `/c/ajax/ajax_calendar.asp` 도 있으나 계약리스트가 주 화면

> ⚠️ 이름과 휴대폰번호만 알면 **타인의 계약·시공·금액 정보를 조회할 수 있다.**
> 둘 다 비밀정보가 아니다. 신규 설계에서 일회용 링크 또는 본인확인 토큰으로 반드시 교체할 것.
