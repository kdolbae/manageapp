# 집대리 — 세금·증빙 & 정산주기

> 2026-07-23. [12](12_결제정산_수수료_AS보증.md) 상위. ※ 기획 + 세무 플래그(세무사 확인 필요).

---

# 1. 정산주기 — 월말 기본 + 즉시 옵션

- 기본: **월말 정산**.
- 초기/특정 파트너: **즉시 지급** 가능.
- → 파트너별 **정산주기 설정**(월말 | 주간 | 즉시 | 시공완료+N일).
- 참고: 영세 시공자에겐 **빠른 정산 = 강력한 유인**(현금회전). 요금제/등급으로 차등 가능.

---

# 2. ★ 핵심 — 세금 3종은 "택1"이 아니라 각기 다른 거래에 적용된다

| 거래 | 증빙 | 대상 |
|---|---|---|
| **① 소비자 판매** | **현금영수증**(개인) / **세금계산서**(사업자 소비자) / 카드전표 | 판매자 → 소비자 |
| **② 중개수수료** | **세금계산서**(+부가세 10%) | 집대리 → 파트너 |
| **③ 매니저 지급** | **3.3% 원천징수** + 지급명세서 | 집대리 → 컨설턴트(개인) |

→ ①②③이 **동시에 다 일어난다.** 시스템은 셋 다 처리해야 함.

## 2.1 각 흐름 상세
**① 소비자 판매** (판매자가 발행)
- 소비자 **개인** → 현금영수증(현금·계좌) / 카드결제는 카드전표가 증빙.
- 소비자 **사업자** → 세금계산서.
- ※ 현행 시스템이 **이미** 세금계산서/현금영수증 발행여부를 계약마다 기록(§01) → 계승.

**② 중개수수료** (집대리 수익)
- 집대리 → 파트너에게 **중개수수료 세금계산서**(공급가 + 부가세).
- 파트너: 전체 매출을 수익으로, 수수료를 비용으로 인식.

**③ 매니저(컨설턴트) 지급**
- 개인 프리랜서(설계사형) → **3.3% 원천징수** 후 지급, 지급명세서 제출.
- ※ 현행 영업자 **지급명세서**(§04)와 동일 메커니즘 → 계승.
- 매니저가 사업자면 → 매니저가 집대리에 세금계산서.

---

# 3. ⚠️ 구조 결정 — 집대리는 "중개자"인가 "판매자"인가 (세무사 확인)

이게 세금 구조 전체를 가른다.

| 구조 | 소비자 증빙 | 집대리 매출 | 평가 |
|---|---|---|---|
| **중개자(권장)** | **파트너**가 소비자에 발행 | **수수료만** | 매출 작음 → 부가세·법인세 base 작음. 규제(통신판매중개)와도 일치 |
| 판매자(재판매) | 집대리가 소비자에 발행 | **전체 GMV** | 매출 폭증(불리) + 매입/재판매 복잡 |

> **권장: 중개자.** 집대리 매출 = 중개수수료만. 전체 거래액이 집대리 장부로 안 흐름.
> (배민·집닥 등 표준 구조) → **세무사와 최종 확정** 필요.

## 3.1 결제수취와의 관계
- 집대리가 **돈은 받지만**(§12 PG 정산대행), **판매자는 파트너**.
- 표준 마켓 구조: 집대리 수취 → 순액 정산 → **파트너가 소비자에 증빙 발행** + **집대리가 파트너에 수수료 계산서**.
- 결제수취(전자금융)와 판매자지위(세금)는 **별개** → 둘 다 챙겨야 함.

# 4. 시스템 설계 — 당사자별 세금 프로파일

```
TaxProfile (당사자마다: 소비자/파트너/매니저/기사)
  entityType: 개인 | 개인사업자 | 법인
  bizNo?
  defaultDoc: 현금영수증 | 세금계산서 | 원천징수(3.3%)

Ledger 금액은 항상 [공급가 + 부가세] 분리 저장  ← 현행 공급가 통계(§04)와 일치
증빙 발행 이력: 종류·번호·일자·상태·연동결과
원천징수 이력: 대상·율·세액·지급명세서 제출
```

## 4.1 실무 도구 — 발행 API 대행
국세청 직접연동 대신 **전자세금계산서/현금영수증/원천징수 발행 대행 API**(예: 팝빌 등) 사용:
- 세금계산서·현금영수증·지급명세서를 **API로 자동 발행/집계**.
- 무팀·고속 원칙에 부합(직접 안 만듦).

---

# 5. 현행이 이미 하는 것 (계승)
- 계약별 **세금계산서/현금영수증 발행여부 + 번호**(§01)
- **공급가/부가세** 분리 집계(§04 통계 전반)
- 영업자 **지급명세서**(§04) = 매니저 3.3% 지급명세서와 동일
→ 새 영역이 아니라 **정식화 + 마켓 수수료 계산서 흐름 추가**.

# 6. 종합
```
소비자 결제 ─PG정산대행→ 집대리 수취
  ├ 판매증빙: 파트너 → 소비자 (현금영수증/세금계산서)   ①
  ├ 수수료 세금계산서: 집대리 → 파트너 (+VAT)           ②
  └ 매니저 지급: 3.3% 원천징수 + 지급명세서             ③
정산: 월말 기본 / 즉시 옵션 (파트너별)
집대리 매출 = 수수료만 (중개자 구조, 세무사 확정)
```
