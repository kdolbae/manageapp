# 집대리 — 컨설턴트 양성 & 이탈방지(Disintermediation)

> 2026-07-23 전략. [10](10_컨시어지모델_컨설턴트중개.md) 상위. ※ 기획/전략. 내 관점 포함.

---

# 1. 컨설턴트 조직 = 보험 설계사형 GTM

- 지역별로 사람을 **지원금(정착지원)** 으로 모집 → 시공 상품 수시 교육 → 판매.
- AS·재계약·시공 후 추가건도 **담당 매니저**가 이어서.
- 커미션 기반 → **자본 효율적이고 빠르게 확장**되는 검증된 방식(보험·방판).

## 1.1 ⚠️ 법적 경계 — 다단계 회피
- 단일 계층(매니저가 **자기 판매**로만 수익) = 합법(방문판매원/설계사).
- **하위 모집 + 후원수당**(내가 뽑은 매니저의 매출에서 수당)이 끼면 → **다단계판매업**(방문판매법) 등록·규제 대상.
- → **싱글 티어로 설계.** 매니저는 자기 계약에서만 벌게. (구체 구조는 전문가 확인 권장)

---

# 2. 이탈 문제 재정의 — 진짜 리스크는 "매니저"

이 모델에서 disintermediation은 두 갈래인데 무게가 다르다:

| 누가 | 리스크 | 이 모델에선 |
|---|---|---|
| **매니저** | 소비자+파트너 양쪽 관계를 쥐고 플랫폼 빼고 직거래 | **가장 큼** (설계사가 book 들고 나가는 문제) |
| 파트너 | 소개받은 고객과 직거래 | **작음** — §7 선정전략으로 이미 완화 |

→ 방어의 초점은 **매니저**다.

---

# 3. 대원칙 — 완벽 방지는 없다. 4개 레버로 관리한다

> 보험사도 설계사 이직·고아계약을 "없애지" 못한다. **관리**한다.
> 목표 = 이탈을 0으로 만드는 게 아니라, **플라이휠이 이기는 수준 이하로** 누르는 것.

| 레버 | 핵심 | 수단 |
|---|---|---|
| **L1 안 하는 게 이득** | 남는 게 더 벌게 | 낮은 수수료 + **유지수수료(trailing)** + 정착금 vesting/clawback + 승진·시책 |
| **L2 못 하게** | 못 떼가게 | ★ **리드(수요) 소유** + 공급망 + 결제/보증을 플랫폼이 쥠 |
| **L3 들키게** | 새면 보이게 | 데이터·행동분석 + 비우회 계약조항 |
| **L4 필요 없게** | 안 나가도 됨 | 도구·브랜드·소비자충성 |

---

# 4. L2 — 가장 깊은 방어: "플랫폼이 수요를 만든다" ★★

매니저가 뗄 수 있는 건 **이미 맺은 관계**뿐, **파이프라인은 못 뗀다.**
- 신규 고객이 전부 **집대리 소비자 앱(에누리 요청)** 에서 나오면,
  매니저가 나가도 **수요는 앱에 남는다.**
- 나간 매니저는 **스스로 리드를 만들어야** 함 = 다시 원점 = 어렵다.
- (우버 기사가 쉽게 직거래 못 하는 이유 = 승객 수요를 혼자 못 만듦)

→ **소비자 수요 생성에 최대 투자.** 이게 제일 강한 해자.

## 4.1 결제·보증을 플랫폼이 쥔다
- 결제가 **집대리 안전결제**로 흐르면 소비자는 **개인 매니저가 아니라 플랫폼을 신뢰**.
- 직거래 = 그 안전장치·보증을 잃음 → 소비자가 저항.
- (집닥의 안전거래와 동일 원리)

## 4.2 공급망을 개인이 못 복제
- 번들 협상은 **여러 파트너의 실시간 단가·가용일**이 있어야 가능.
- 개인 매니저가 수십 개 파트너 관계를 혼자 유지 못 함 → 플랫폼이 공급을 집약.

---

# 5. L1 — 남는 게 더 벌게 (보험의 리텐션 도구 차용)

매니저 모델을 보험에서 가져왔으니 **보험의 이탈방지 장치도 그대로** 쓴다:

| 장치 | 내용 |
|---|---|
| **유지수수료(trailing)** | 자기 book의 재계약·AS·추가건에서 **계속 나오는 수수료** → 나가면 이 흐름이 끊김 |
| **정착지원금 vesting** | 초기 지원금을 **분할 확정**, 조기 이탈·우회 적발 시 **환수(clawback)** |
| **승진·등급·시책** | 볼륨·유지율 기반 등급 상승, 보너스 → 남을수록 유리 |
| **낮은 수수료** | 사용자 안대로 최소화 → **떼먹어봤자 이득 작고 리스크 큼** |

> 핵심: **잔류의 경제적 가치 > 이탈의 일시 이득**이 되게 설계.

---

# 6. L4 — AS/보증을 "리쉬(leash)"로 ★

기존 계약약관의 **10년 A/S**를 리텐션 장치로 전환:
- AS·보증은 **집대리를 통해야 인정**(플랫폼 보증).
- 그러면 몇 년 뒤에도 소비자가 **AS 때문에 앱으로 돌아옴** → 재계약·추가건이 **자연히 온플랫폼**.
- **보증 = 소비자를 붙잡는 목줄.** 매니저가 소비자를 빼가기 어려워짐.

## 6.1 소비자 충성을 "브랜드"로 (매니저 아님)
- 소비자가 **"집대리"(브랜드·보증·후기)** 를 신뢰하게 → "김 매니저"는 얼굴일 뿐.
- 매니저가 나가도 소비자는 남고 **새 매니저 배정**.
- (삼성생명을 믿지 설계사 개인을 믿는 게 아니듯. 설계사는 교체 가능.)
- → 앱·보증·이력·후기를 **소비자 소유물**로 앱에 쌓아야 성립.

---

# 7. 파트너 선정 = 그 자체가 해자 ★★

사용자 전략: **영업력 강한 업체 말고, 영업력 없지만 성실한 시공자 위주.**
→ 이건 단순 품질 얘기가 아니라 **이탈방지의 핵심 설계**다.

| 왜 강력한가 | 설명 |
|---|---|
| **스티키한 공급** | 영업력 없는 시공자는 **스스로 고객을 못 구함** → 플랫폼의 수요에 의존 → 안 떠남 |
| **직거래 유인 낮음** | 자기 고객 획득 채널이 없으니 빼갈 것도 없음 |
| **품질=연료** | 성실한 시공 = 좋은 후기 = 소비자 경험 = 플라이휠 연료 |
| **마켓플레이스 정석** | "스스로 수요를 못 만드는 공급"을 모은다 (우버가 자체 배차 있는 택시회사 말고 개인기사를 모은 것과 동일) |

> 영업 잘하는 업체 = 떠날 업체. 성실하지만 영업 못하는 시공자 = **플랫폼이 딱 필요한, 안 떠나는 공급.**
> 파트너 선정 기준이 곧 해자다. 이 방향 **강력 지지.**

---

# 8. 종합 — 이탈방지 스택
```
수요를 플랫폼이 소유(L2)  ← 가장 깊음. 나가도 파이프라인 못 뗌
  + 결제·보증을 플랫폼이 쥠(L2) ← 소비자 신뢰가 브랜드로
  + 잔류가 더 벌게(L1)      ← 유지수수료·정착금 vesting·시책
  + AS/10년보증 = 리쉬(L4)  ← 소비자가 앱으로 돌아옴
  + 브랜드 충성(L4)         ← 매니저는 얼굴, 집대리가 브랜드
  + 성실시공자 공급(§7)     ← 안 떠나는 공급을 애초에 선택
  + 데이터 감지·계약(L3)    ← 백스톱
= 완벽 방지 ✗ / 플라이휠이 이기는 수준으로 관리 ✓
```
