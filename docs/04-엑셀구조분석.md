# 엑셀 → DB 구조 생성 (데이터 미포함)

UPIS에서 내보낸 엑셀을 읽어 **어떤 테이블이 있고 어떤 컬럼이 있는지 분석**하고,
**테이블 구조(DDL)만** 생성합니다. 실제 행 데이터는 적재하지 않습니다.

- 도구: [`scripts/inspect-excel.ts`](../scripts/inspect-excel.ts)

## 규칙

| 엑셀 | → | DB |
| --- | --- | --- |
| 워크시트(시트) | → | 테이블 1개 |
| 첫 데이터 행(헤더) | → | 컬럼 목록 |
| 셀 값 스캔 | → | 컬럼 타입 추론 |

타입 추론: `BOOLEAN · BIGINT · NUMERIC · DATE · TIMESTAMP · TEXT`
(빈 셀이 있으면 해당 컬럼은 NULL 허용). 원본 컬럼명은 그대로 보존하며 Postgres에서
큰따옴표로 인용됩니다(한글 컬럼명 지원).

## 사용

```bash
# 파일 하나 또는 폴더(여러 엑셀) 지정
npm run inspect:excel -- ./data/upis.xlsx
# 또는
npx tsx scripts/inspect-excel.ts ./data/ --schema upis
```

옵션: `--schema <이름>`(기본 upis), `--out-md <경로>`, `--out-sql <경로>`, `--sample <개수>`

## 산출물

- `docs/upis-schema.generated.md` — 테이블·컬럼·타입·샘플 카탈로그(사람이 검토)
- `prisma/sql/upis_tables.generated.sql` — `CREATE TABLE` DDL(구조만)

## 구조 적용(선택)

```bash
psql "$DATABASE_URL" -f prisma/sql/upis_tables.generated.sql
```
