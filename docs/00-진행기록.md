## 1. 출발점

저장소는 **완전히 빈 상태**(커밋 0, 브랜치 없음)에서 시작했습니다.
따라서 "유피스(UPIS) 계약관리 시스템 정보"는 저장소 안에 존재하지 않았고,
모든 것을 처음부터 설계·구축했습니다.

## 2. 확정된 목표

> UPIS DB를 모두 가져와, 올해 안에 **UPIS를 대체하는 서비스**를 갖추고,
> 계약 데이터를 **완전히 자산화**한다.

## 3. 주요 결정 사항

| # | 논점 | 결정 | 근거 |
| --- | --- | --- | --- |
| 1 | "완전 자산화"의 정의 | **데이터 자산화** | 흩어진 계약 데이터를 표준화·통합해 재사용 가능한 자산으로 축적하는 것이 핵심 |
| 2 | 기술 스택 | **Next.js(App Router) + TypeScript + Prisma + PostgreSQL** | 단일 코드베이스, 스키마 우선 설계, 국내 SaaS에 검증된 조합 |
| 3 | 데이터 아키텍처 | **3계층(메달리온)**: `stg`(Bronze) → `core`(Silver) → `asset`(Gold) | 레거시 스키마를 모르는 상태에서도 원본을 손실 없이 보존하고 단계적으로 표준화하기 위함 |
| 4 | 기능 범위 | **전 기능을 담은 통합 관리 프로그램** | "모든 기능이 담긴 새 관리 프로그램" 요구에 따라 AI가 기능 세트를 확정하고 리드 |
| 5 | DB 설계 범위 | **UPIS 전 영역을 수용하는 superset 설계** | 실제 테이블 목록 확보 전이므로, 넓게 설계해두고 확인되면 매핑·가감 |
| 6 | 데이터 이관 방식 | 당장은 **데이터 미적재**, 구조만 | "데이터는 가져오지 말고 구조(테이블 종류)만 만들어라"는 요청 반영 |

### 자산화의 4요소 (설계 기준)

| 요소 | 구현 위치 |
| --- | --- |
| 표준 스키마 | `core` 계층 + `DataAssetField`(데이터 사전) |
| 계보(Lineage) | `DataLineage` + 코어의 `sourceSystem`/`sourcePk` provenance 필드 |
| 품질(Quality) | `DataQualityCheck` (완전성/유효성/유일성/정합성/적시성) |
| 카탈로그 | `DataAsset` (자산 목록·소유자·갱신주기) |

### 애플리케이션 (동작 확인 완료)
대시보드 / 계약 / 거래처 / 정산 / 데이터 자산 카탈로그 / 사용자 — 총 14개 라우트.
계약 생애주기 상태 전환, 변경계약(개정), 품목·문서·정산·활동이력, 연체 관리,
PII 마스킹 등을 포함합니다.

### DB 설계 (`prisma/schema.prisma`)
UPIS 전 영역을 담는 종합 설계 — 조직/사용자, 거래처(+계좌), 계약(유형·다자당사자·조항·마일스톤),
문서(버전), 이력, 결재선, 재무(정산·세금계산서), 알림, 공통코드, 감사로그.

### 도구
- `scripts/inspect-excel.ts` — 엑셀을 읽어 **시트=테이블, 헤더=컬럼**으로 구조 분석 후 DDL 생성 (데이터 미적재)
- `scripts/crawl-uffice.ts` — UPIS 화면 구조를 **읽기 전용**으로 수집 (메뉴·목록 컬럼·폼 필드)
- `scripts/ingest-upis.ts` — UPIS → Bronze 적재 스켈레톤 (어댑터 미구현)

## 5. 시도했으나 막힌 것

### UPIS(`nm00.uffice.kr`) 직접 접속 — **차단됨**
클라우드 실행 환경의 네트워크 정책이 해당 도메인을 막고 있습니다.
프록시가 CONNECT 단계에서 403(`connect_rejected — policy denial`)을 반환합니다.

**대응**: 크롤러는 완성·검증(Chromium 기동 확인)해 두었고,
[`05-로컬-크롤링-프롬프트.md`](05-로컬-크롤링-프롬프트.md)의 프롬프트로
**사용자 본인 PC의 Claude Code에서 실행**하면 동일한 결과를 얻습니다.

> 참고: 환경 네트워크 정책을 변경하더라도 **이미 실행 중인 세션에는 반영되지 않고
> 새 세션부터 적용**됩니다.

## 7. 보안 메모

- 자격증명은 `.env`(gitignore)에만 두었고 **저장소에는 커밋되지 않았습니다.**
- UPIS 계정 비밀번호가 대화 중 평문으로 공유되었으므로 **변경을 권장**합니다.
- 계약 데이터에는 개인정보가 포함될 수 있어, `DataAssetField.isPii` 표시와
  화면 마스킹(`regNo`)을 적용했습니다. 이관 시 접근통제·보존기간 정책이 필요합니다.
- UPIS 원본 덤프/추출물은 `/data`, `*.dump`, `*.sql.gz`로 **커밋 차단**되어 있습니다.
